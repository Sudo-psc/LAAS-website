## 📊 ESPECIFICAÇÕES TÉCNICAS

### Formatos Recomendados:
- **Fotos:** JPEG (qualidade 85%) ou WebP
- **Ícones:** SVG (escalável) ou PNG (transparência)
- **Gráficos:** SVG (animado quando possível)
- **Vídeos:** MP4 (H.264) ou WebM

### Otimização:
- [ ] Compressão de imagens sem perda de qualidade
- [ ] Lazy loading para imagens abaixo do fold
- [ ] WebP para browsers compatíveis
- [ ] Tamanhos responsivos com srcset

### Acessibilidade:
- [ ] Alt text descritivo para todas as imagens
- [ ] Contraste adequado em ícones
- [ ] Tamanhos mínimos para toque em mobile
- [ ] Labels ARIA para elementos interativos

## 📝 NOTAS FINAIS

### Recomendações:
1. **Consistência visual:** Manter o mesmo estilo em todos os ícones
2. **Qualidade sobre quantidade:** Melhor poucas imagens de alta qualidade
3. **Performance:** Otimizar todas as imagens para web
4. **Acessibilidade:** Garantir que todos os elementos visuais sejam acessíveis
5. **Autenticidade:** Usar fotos reais sempre que possível

### Ferramentas Sugeridas:
- **Design:** Figma, Adobe Illustrator
- **Otimização:** TinyPNG, ImageOptim
- **Ícones:** Lucide, Heroicons, Feather Icons
- **Fotos:** Unsplash, Pexels (como referência)
- **SVG:** SVGOMG para otimização
